Revisão

rascunhos gerados por IA ou manuais · a decisão final é sempre sua
O Aegis monta um prompt com o que foi medido (executável real, IP/porta/protocolo/direção, regras existentes) e o motor de IA é o seu — Thero/Zeus respondem via arquivos, como no Sentinel. JSON malformado é rejeitado com o trecho apontado; nenhum rascunho vira regra sem o seu clique.

Transparência

o contrato entre o Aegis e a sua máquina
✓ O que o Aegis faz
  • ✓Lê regras, conexões e bloqueios como usuário normal, sem admin
  • ✓Explica o porquê de cada bloqueio em linguagem humana
  • ✓Mostra exatamente a linha que será escrita antes do UAC
  • ✓Confere cada regra aplicada relendo o firewall
  • ✓Registra tudo num log de auditoria local legível aqui embaixo
✗ O que o Aegis nunca faz
  • ✗Bloqueia ou libera algo por conta própria — não existe modo "auto"
  • ✗Apaga arquivos, quarentena ou "protege você no susto"
  • ✗Sobrescreve regra do sistema ou de antivírus sem mostrar o conflito
  • ✗Envia dado algum para a nuvem — o motor de IA é local/seu
  • ✗Fica residente elevado — só o helper pontual pede UAC
